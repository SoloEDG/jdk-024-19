# 静水手记

安装：`npm install`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18224。

## 钓手契约

挑战不再按累计计数，而是按「事件顺序」结算：

- 每个阶段有前置契约，领奖后才会打开；打开那一刻记下事件边界，开约前的
  收获一律不补算。
- 一个阶段可含若干互斥路线，任选一组。组内步骤必须按顺序完成：在连续
  若干竿内用指定饵捕获或放流指定鱼种，也可以放流同一尾刚捕到的鱼。
- 同一尾鱼可以同时出现在多份未提交契约的预览窗口里；正式结算时每批见证
  事件只归一个阶段，重复领取不会二次消耗证据或重复发奖。
- 互斥路线提交一条后，另一条未领奖的阶段放弃，不会补发；已领奖的阶段
  永不回滚。
- 重试 / 换约只重开当前阶段；刷新、断线、跑鱼、放流、换约都按同一事件
  顺序推进一次。
- 长手记只保留活跃窗口所需的原始事件，压缩后仍在阶段记录里保留见证事件
  与失败原因，而不是只剩计数。

契约引擎是无浏览器依赖的纯函数，验证脚本：

```bash
npx esbuild harness/engine.test.ts --bundle --platform=node --format=cjs \
  --outfile=/tmp/contract-run/test.js
node /tmp/contract-run/test.js
```
